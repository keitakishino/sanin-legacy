明細に一つ: カード名、エキスパンション・foil・フレーム
明細に複数: 金額(ドル)・数量、ユーザー名(またはユーザーID)・注文数
金額と数量、ユーザー名(またはユーザーID)と注文数はそれぞれ紐づいて1:1の対応を取る
